# OrthoFlow Frontend

Angular 22 foundation for the OrthoFlow orthodontic practice-management platform. The current milestone contains only the public marketing experience and early-access form.

## Local development

Use Node 22.22.3+, 24.15+, or 26+, then run:

```bash
npm install
npm start
```

Open `http://localhost:4200`. Before submitting changes, run:

```bash
npm run lint
npm test
npm run build
npm run format:check
```

Read `AGENTS.md` and `design.md` before changing product scope or interface design.
